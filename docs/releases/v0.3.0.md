# Genyx 0.3.0 — Portfolio and catalog release candidate

## Verified baseline

The integrated Sprint 2.5 candidate passed CI and CodeQL at commit 426fe00.
See [CI](https://github.com/Holger2005/genyx/actions/runs/45930821832)
and [CodeQL](https://github.com/Holger2005/genyx/actions/runs/45930821833).

- 19 unit tests across seven files.
- 100 percent coverage of the selected domain and application code only.
- Zero vulnerabilities reported by npm audit at that time.
- HTTP and Chromium checks passed; local prototype captures were uploaded.
- Decoded homepage JavaScript: 473971 bytes in both languages.

## Laboratory release gate

The Node.js 24 CI job uses Lighthouse 13.6.0 on the local production server.
It runs mobile audits of home, portfolio, case study, services and products in
both locales, plus both desktop homepages. Reports are retained for seven days.

- Performance score: at least 95 out of 100.
- Accessibility score: at least 95 out of 100.
- Laboratory LCP: at most 2500 ms.
- Laboratory CLS: at most 0.1.
- Laboratory total blocking time: at most 200 ms.

Best practices and SEO scores are recorded but not used as release thresholds.
Search indexing is intentionally disabled, so SEO scoring can reflect that choice.
The CLI version is pinned; its temporary npm tool dependency graph is not locked
by the application lockfile. No new runtime or application dependencies were added.

These are synthetic measurements, not field Core Web Vitals or WCAG conformance.
TBT is not INP. Real-user INP, real-device and manual accessibility checks remain open.
A failing score must be investigated; do not lower thresholds to claim success.

## Release gates

- [ ] Pass CI and CodeQL on the candidate, including all Lighthouse budgets.
- [ ] Review the laboratory reports and actual browser captures.
- [ ] Merge the accepted release candidate into develop.
- [ ] Promote the exact reviewed tree through a fresh main-target pull request.
- [ ] Verify CI on main before creating a version tag.

## Commercial gates

Contact and appointment integrations, approved external portfolio media, commercial
SaaS availability, production CSP and HTTPS/HSTS, legal notices, privacy controls,
real-device testing and hosting approval remain open. Do not enable search indexing
until the actual commercial site is approved.

This release is a technical portfolio prototype, not a public commercial launch.
