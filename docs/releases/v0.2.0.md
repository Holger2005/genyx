# Genyx 0.2.0 — Visual prototype release candidate

## Scope

This release is a development milestone, not a public commercial launch. No customer
data, working contact forms, appointment integration, verified portfolio media or
production deployment is included. Search indexing remains disabled.

- [ ] Real GPU rendering, context-loss recovery and mobile/cross-browser visual testing.
- [ ] Final art direction and complete cross-route transitions.
- [ ] Complete CSP, HTTPS/HSTS and administrative security alert verification.
- [ ] Verified portfolio content, publication permissions and functional commercial flows.
- [ ] Commercially permitted hosting and deployment validation.

Do not present the release candidate as production-ready or certified. Do not bypass
failing checks. If a regression occurs, revert via pull request.
